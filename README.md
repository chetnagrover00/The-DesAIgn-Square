## About

A single-page marketing site for the community. Built as a static site with hand-written HTML, CSS, and vanilla JS — no framework, no build step.

- **Fonts:** Teko (display) + Raleway (body)
- **Palette:** black · lime `#e1f000` · magenta `#ff1cba` · blue `#545eff`
- **Join:** WhatsApp community (updates) · **Register:** Commudle (tickets)

## Structure

```
index.html      # the full single page
styles.css      # all styles
script.js       # mobile nav, scroll reveals, small interactions
assets/         # logos, founder photo, illustrated glimpses
source/         # original high-res source images
```

## Run locally

Any static server works, e.g.:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000
